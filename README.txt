EVENTOS PRESTIGE - FRONTEND
1. Abre la carpeta en VS Code y ejecuta con "Live Server" (los módulos JS NO funcionan abriendo el .html con doble clic).
2. Cambia la URL de la API en js/config.js (API_BASE_URL).
3. El backend debe tener CORS habilitado para el origen de Live Server (http://127.0.0.1:5500).
4. Agrega tus imágenes en la carpeta img/.
